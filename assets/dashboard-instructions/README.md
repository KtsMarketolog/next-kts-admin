Файлы не должны размещаться в `public`. Выдача — только через
`/api/admin/dashboard-instructions/[kind]`, с проверкой действующей сессии и
доступа к конкретному отчёту. Для аналитики продаж дополнительно проверяется
профиль опубликованного HTML, а не изменяемое название раздела.

При замене инструкции обновлять реестр `dashboardInstructions.ts`, контрольные
суммы в тестах и этот файл. `next.config.ts` включает PDF и MP4 в standalone-сборку.
Для видео используется тот же защищённый endpoint с `format=video`, для PDF
параметр можно не указывать. MP4 — H.264/AAC с метаданными в начале файла,
поддерживается Range для перемотки. Плеер создаётся только по нажатию пользователя;
автозапуска и предварительной загрузки видео при открытии отчёта нет.
