# Необязательный журнал счетов: invoice-v1

Самостоятельный HTML-отчёт можно обновлять без подключения этого протокола.
Права доступа, публикация, откат и учёт открытия отчёта от него не зависят.
Без подключения сайт не записывает подробности счетов и не пытается извлечь их
из переменных, текста страницы или произвольных пользовательских файлов.

Проверенный V19 сохраняет прежний адаптер без изменений авторских расчётов.
Для новых отчётов автор один раз подключает стабильный контракт, не зависящий
от номера версии или контрольной суммы приложения.

## Подключение автором HTML

В явном `<head>` документа укажите один тег:

```html
<meta name="kts-dashboard-audit" content="invoice-v1">
```

Сайт добавит `window.KTSDashboardAudit` до выполнения авторского приложения.
Тег в комментарии, строке JavaScript, шаблоне или теле документа не является
подключением. Неизвестная версия контракта или несколько деклараций не включают
журнал. Сохраняйте декларацию и вызовы API в следующих версиях HTML.

После **успешного** распознавания выбранного пользователем счёта или КП вызовите:

```js
const eventId = window.KTSDashboardAudit?.recordInvoice({
  schemaVersion: 1,
  documentType: 'invoice',             // 'invoice' или 'quote' (КП)
  invoiceNumber: '123/10',             // null, если номер не распознан
  currency: 'USD',                    // исходная валюта, не валюта расчёта
  dealAmount: 125.50,                  // исходная сумма либо null
  amountSource: 'document',           // 'document', 'lines', 'unavailable'
  lines: [
    { nomenclature: 'Наименование из документа', quantity: 2 }
  ]
}, originalFile);
```

`originalFile` — тот же объект `File`, который получен из настоящего выбора
пользователем (`input type="file"`) или перетаскивания. Любые имена и идентификаторы
поля поддерживаются. Копирование `File`, автоматическая подстановка `DataTransfer`,
встроенный пример и автоматическое восстановление состояния не считаются
пользовательской загрузкой. Имя и размер файла передаются в журнал, байты файла
этот API не читает и не отправляет.

Вызов возвращает идентификатор поставленного в очередь события, **не подтверждение
записи на сервер**. `null` означает, что событие не поставлено в очередь. При
проверке данных возникает видимое предупреждение; исходный расчёт не прерывается.
Транспорт, повторные попытки и подтверждение сервера выполняет сайт. Состояние
очереди показано в уведомлении; страницу нельзя закрывать до подтверждения.
Повтор одного и того же канонического объекта с тем же `File` возвращает тот же
идентификатор и не создаёт дубль. Повторная самостоятельная загрузка нового `File`
считается новым действием. Для двух полностью одинаковых счетов внутри одного
снимка этот контракт записывает одно событие; для раздельного учёта выбирайте
исходные файлы по отдельности.

## Смысл данных и ограничения

- Отправляйте только исходные позиции счёта/КП. Ручные позиции, доставка, закупочные
  цены, маржа, скидки и пересчитанные суммы в этот контракт не входят.
- «Расчёт без счёта» не является загрузкой счёта и не вызывает `recordInvoice`.
  Для обычных событий расчёта используется отдельный, не содержащий финансовых
  подробностей журнал поддерживаемых действий.
- Не вызывайте API при ошибке импорта, на выборе файла до разбора, при открытии
  демо или автоматическом восстановлении. Если пользователь явно загрузил снимок,
  передавайте только исходные счета/КП из него, не сохранённые ручные расчёты.
- Разрешены только перечисленные ключи. Номер — до 200 символов либо `null`;
  валюта — три заглавные латинские буквы; сумма — конечное число по модулю до
  `1e15` либо `null`; позиции — от 1 до 1000; наименование — до 500 символов;
  количество — конечное число по модулю до `1e12`. Отрицательные и дробные
  исходные значения сохраняются без изменения. Управляющие символы запрещены.
- `amountSource: 'unavailable'` требует `dealAmount: null`, остальные источники
  требуют число. При отсутствии итоговой суммы можно передать сумму исходных
  позиций с `amountSource: 'lines'`, не результат расчёта в рублях.
- Финансовое событие ограничено 1 МиБ, очередь — 100 неподтверждённых записей.
  Превышение не обрезает данные молча. Подготовка записи не меняет работу расчёта.
- Журнал означает **событие, сообщённое HTML-отчётом**, а не независимое доказательство
  распознавания, корректности документа или работы сотрудника. Сайт проверяет
  форму данных, права, активную версию и идемпотентность, но не читает документ
  повторно для проверки утверждений авторского приложения.

Идентификатор сотрудника, время регистрации, отчёт, версия и режим предпросмотра
определяются доверенной частью сайта. Подмена этих полей из HTML запрещена.
Предпросмотр и черновик доступны по прежним правам; декларация не даёт новых прав.
Подробности не передаются в обычные события или общие снимки. Публикация HTML сама
по себе не загружает выбранные сотрудником частные счета на сервер.
