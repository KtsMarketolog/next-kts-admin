# Импорт остатков из почты

Импорт остатков обновляет только наличие товаров. Он не создает товары, категории, подкатегории и бренды, не меняет названия, цены, картинки и структуру каталога.

## Env

Добавить на сервер в `.env.local`:

```env
STOCK_MAIL_HOST=
STOCK_MAIL_PORT=993
STOCK_MAIL_SECURE=true
STOCK_MAIL_USER=
STOCK_MAIL_PASSWORD=
STOCK_MAIL_ALLOWED_FROM=
STOCK_MAIL_SUBJECT=
STOCK_MAIL_FILENAME_PREFIX=Остатки
STOCK_MAIL_PROCESSED_FOLDER=Processed
STOCK_MAIL_ERROR_FOLDER=ImportErrors
```

Пароль почты хранится только в env. В код его не добавлять.

## Формат Excel

Поддерживается только `.xlsx`. Первый лист должен содержать колонки:

| Наименование | Остаток | Ожидается |
| --- | ---: | --- |
| Дверь липа 1800х700 | 12 | нет |
| Дверь стеклянная бронза 1900х700 | 0 | да |

Правила:

- `Наименование` обязательно. Товар ищется по точному названию после `trim`, замены неразрывных пробелов и схлопывания лишних пробелов.
- `Остаток` обязателен, целое число `>= 0`.
- `Ожидается` обязательно: `да`, `нет`, `true`, `false`, `1`, `0`.
- Если товар не найден или найдено несколько товаров с одинаковым названием, строка не обновляется.
- Товары, которых нет в файле, не обнуляются.

## Запуск

Вручную из консоли:

```bash
npm run stock:import-email
```

В админке:

`/admin/site?section=catalog` → блок `Импорт остатков` → `Проверить почту сейчас`.

API для ручного запуска:

```http
POST /api/admin/stock-import/check-email
```

Endpoint доступен только авторизованному администратору.

## Cron на VPS

Пример запуска каждые 10 минут:

```cron
*/10 * * * * cd /home/deploy/apps/PROJECT/current && npm run stock:import-email >> /var/log/stock-import.log 2>&1
```

Путь заменить на фактический путь проекта.

## Логи

Результаты сохраняются в `stock_import_logs`:

- дата импорта;
- имя файла;
- отправитель;
- тема письма;
- статус;
- всего строк;
- обновлено;
- не найдено;
- ошибок;
- JSON со списком ошибок.

Для защиты от параллельного запуска используется таблица `stock_import_locks`. Если предыдущий импорт завис, lock старше 30 минут считается устаревшим.
